경로 옵션

자동차 기본 경로
자전거 기본 경로
자동차 "추천"은 실시간 교통을 반영한 가장 빠른 길이에요. 자전거는 카카오 REST API 키가 있으면 카카오 자전거도로 DB로 먼저 계산하고, 없으면 "자전거도로 우선" 설정 시 무료 엔진(BRouter)으로 계산합니다.

저장 장소 (우리집 / 회사 등)

주소를 입력하면 좌표로 변환해 저장합니다. 명령에서 "우리집에서 회사까지 버스로" 처럼 쓸 수 있어요.

도보 경로 (TMap)

기본 내장 키로 동작 중이라 별도 입력 없이 바로 쓸 수 있어요. 자기 키를 쓰고 싶으면 여기에 입력하세요. 비우면 내장 기본 키로 돌아갑니다. 키가 없거나 연결에 실패하면 공개 서버(OSM)로 계산합니다.

주유소 가격 (오피넷)

"근처 주유소" 검색 시 주유소별 실시간 가격을 가격순으로 보여줘요. 키는 앱에 내장되어 있어 별도 입력 없이 바로 쓸 수 있어요. 자기 키를 쓰고 싶으면 위에 입력하세요. 유종을 바꾸면 다음 검색부터 적용됩니다.

자전거 경로 (카카오)

카카오 자전거도로 DB로 경로를 계산해요. 카카오 개발자 콘솔(내 애플리케이션 → 앱 키)의 "REST API 키"를 입력하세요. 키가 없으면 무료 엔진(BRouter)으로 계산합니다.
